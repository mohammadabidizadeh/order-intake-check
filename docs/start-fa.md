# اجرای نمونه روی ویندوز

فایل ZIP را استخراج کنید و در پوشه‌ای که `README.md` و `ordercheck` در آن هستند، PowerShell را باز کنید. برای این مثال Python 3.14 کافی است.

```powershell
py -3.14 -m ordercheck examples/orders.csv --catalog examples/catalog.csv
$LASTEXITCODE
```

فایل چهار قلم و دو سفارش دارد. در سفارش `PO-101` کد کالای رکورد ۵ در کاتالوگ پیدا نمی‌شود. برنامه برای آن سفارش وضعیت `held`، فهرست اقلام خالی و خطای `unknown_sku` می‌دهد. رکورد ۱ سرستون است. سفارش `PO-100` آماده می‌ماند. کد خروج ۲ یعنی حداقل یک سفارش باید بررسی شود.

پس از تأیید کد صحیح توسط مسئول کاتالوگ، فایل اصلاح‌شده را بررسی کنید.

```powershell
py -3.14 -m ordercheck examples/orders-corrected.csv --catalog examples/catalog.csv
$LASTEXITCODE
```

در نمونهٔ اصلاح‌شده هر دو سفارش آماده‌اند و کد خروج ۰ است. وضعیت «آماده» فقط بررسی همین فایل و نگاشت را پوشش می‌دهد. موجودی، قیمت و ثبت نهایی در سیستم فروش به رسیدگی جداگانه نیاز دارند. در اکسل، شناسه‌ها را به شکل متن نگه دارید تا صفرهای اول کدهایی مثل `00127` از بین نروند.

برای نصب آفلاین API و اجرای تست‌ها، [راهنمای ویندوز](deployment.md) را ببینید.
